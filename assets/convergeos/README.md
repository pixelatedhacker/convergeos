# ConvergeOS app icon

`app-icon.png` is the source artwork for the turquoise and coral ConvergeOS mark.
Run `vp run icons:export` on macOS to regenerate the desktop, web, and shared
mobile PNG and ICO assets. `vp run icons:check` checks the generated files.
The desktop packager converts the macOS PNG into a multi-resolution ICNS.
The upstream Icon Composer projects remain reference material.

Created with the built-in image generation tool. Prompt: a macOS app icon with
a midnight navy tile and bold turquoise and coral paths converging into a
C-shaped mark, with a transparent background outside the tile, no text,
and a silhouette readable at small sizes.
