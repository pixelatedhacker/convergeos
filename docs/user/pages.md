# Saved pages

Pages keeps reports, small tools, and websites with a project. On web and desktop, open the
project home and find Pages. This section appears only when the connected environment supports
saved pages. Projects grouped across environments show each environment's pages separately.

Choose Save a page and give it a title. Upload a self-contained HTML document or save an HTTPS
website address. Documents are stored by the environment. Website links still depend on the
external site being available. Saving here does not publish the document to the public internet.

Select a page to open its content. The list shows the latest saved version. You can rename the
page, archive it, or publish a new document or URL through Publish an update. A simultaneous edit
from another device can reject your update. Close the page and reopen it to load the current
version before retrying. Existing versions are retained when an update is published.

Show archived includes archived pages. Open one and choose Restore page to return it to the list.
Pages linked to a conversation offer Open conversation. Refresh retrieves changes saved by
another device or agent.

On mobile, select Pages above the thread list. Choose a project, open a page, rename it, or
archive and restore it. Saving new pages and publishing updates are available on web and desktop.
HTML documents open in an isolated viewer. Website links open in your browser.

The list shows up to 200 recently updated pages per project. The environment must be connected
to retrieve a saved document, including when viewing from another machine.
