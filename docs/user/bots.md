# Bots

A bot is an agent thread with saved instructions and its own worktree. Create one from Bots in
the web or desktop app. Choose a project, name, instructions, and provider/model, then select
Create bot. The worktree starts from the project's current HEAD. Creation does not send a task.

You can also use an existing thread that already has an isolated worktree. Open the existing
thread section in the creation dialog, then edit the bot to set its instructions.

Send a task from the bot workspace or open its conversation. The Computer section opens only
when you select it. Tasks that need your approval or an answer remain visible in the conversation.
Disabling a bot keeps its conversation and files.

On mobile, select Bots above the thread list. If a project is selected, the list stays within that
project. Open conversation to send work or respond to the bot. Open computer when you need its
desktop. Bot creation and instruction editing are available on web and desktop.
