# Files on mobile

Open a file from the thread's file browser or a file link in chat. Markdown opens as a rendered document. Use the file menu to switch between Preview and Source.

Tap the share button in the file header to share the original file or save a copy. On iPhone and iPad, choose Save to Files in the native share sheet. On Android, choose an available app or storage destination. Documents, source files, images, videos, and archives use the same action, including files whose previews are truncated.

Choose Open file from the menu to use the device's document viewer. iOS uses Quick Look; Android uses an installed app for that format. Files without an in-app preview offer Open file and Share or save directly. You can return to the thread when you finish.

Your environment must be connected to download the file. Update its server along with the mobile app to enable downloads of all workspace file types.
